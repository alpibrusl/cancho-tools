Built for two readers

  
The same binaries, told twice: what a person gets, and what an agent can parse.

  

    
    
  


  

    

      
Safe by default
Writes are atomic and only land if the file is what you said it was. Nothing outside --root can be reached. move never overwrites; there is no delete.

      
The same every time
No locale, no clock, no environment: the same input gives the same bytes. Memory is bounded, about 1.7 MB for a 1 MiB file or a 256 MiB one.

      
Easy to check
Each binary embeds what the compiler found it may do. CI fails if a tool grows past its ceiling. The table below is that data, not a promise.

    

    
# you need git, Rust and clang; the first build takes a few minutes
git clone https://github.com/alpibrusl/cancho
git clone https://github.com/alpibrusl/cancho-tools && cd cancho-tools
REV=$(sed -n 's/^cancho *= *"\([0-9a-f]*\)".*/\1/p' cancho.toml)
(cd ../cancho && git fetch -q origin && git checkout "$REV" && cargo build --release -p cancho)
export PATH=$PWD/../cancho/target/release:$PWD/build:$PATH
cancho build                                  # every tool into build/
seek --root . --format text 'fn main' tools/seek/seek.cho
